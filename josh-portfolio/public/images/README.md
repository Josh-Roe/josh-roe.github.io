# Image slots

These SVG files are temporary placeholders so the site looks complete before real photos are added.

Recommended replacements:

- `profile.svg` — portrait/headshot (roughly 4:5)
- `robotics.svg` — vertical robot / competition image
- `ai.svg` — model UI, graph, or software screenshot
- `hardware.svg` — CAD, hardware, or manufacturing image

You can keep the same filenames by exporting your images as SVG, or change the corresponding `src` values in `src/App.jsx` to `.jpg`, `.png`, or `.webp` files.
